# WHW – Rechner zur betrieblichen Altersvorsorge (HVM)

Online-Rechner der WHW-Hillebrand-Gruppe zur betrieblichen Altersvorsorge (HVM – Hillebrand Vorsorgemanagement). QR-Codes in Einladung und Flyer.

- Rechner: https://olibau.github.io/bav-dashboard-whw/ (Kurz-URL: https://tinyurl.com/whw-bav-rechner)
- Erklärvideo (Weiterleitung): https://olibau.github.io/bav-dashboard-whw/video/ (Kurz-URL: https://tinyurl.com/whw-bav-video)
- `dashboard.html`: Weiterleitung auf den Rechner (frühere Informationsübersicht, 03/2026)

Der Rechner läuft vollständig im Browser – es werden keine Daten gespeichert oder übertragen.
